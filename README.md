## §2. 결과 요약

- 1단계에서 5개 신호 × 4개 지평의 방향성 수익률 가설은 지지되지 않았다.
- D6의 유일한 확증 통과 결과는 후속 스튜던트화·층화 검정에서 유지되지 않았다.
- 반면 S1에서는 사후 경로변동성의 차이가 관측되었으나, 이를 독립적인 확증이나 실용적 예측력으로 해석하지 않는다.
- 따라서 1단계의 결과는 수익률 방향 예측의 미지지와 변동성 차이의 관측으로 요약한다.

## §3. 방법론 요약

- **미래 참조 차단** — 신호는 t일 종가로 확정, 진입은 t+1일 종가
- **무작위 벤치마크 없는 신호 평가 금지** — S&P 500은 표본 내내 우상향했으므로 절대 수익률은 근거가 되지 않는다. 순열검정 B = 10,000, seed 42로 초과분과 p-value만 본다
- **사전등록** — 임계값·검정통계량·해석 규칙을 결과 확인 **전에** 커밋
- **다중검정 보정** — Bonferroni α_adj = 0.0025 (D6~D7), α_read = 0.0125 (D12)
- **벤치마크는 `^SP500TR`** — `^GSPC`는 가격지수라 배당이 빠져 매년 약 2%p 유리해진다
- **거래비용 반영** — 왕복 20 bp, 현금 구간 무위험수익률 포함. 결측치는 보간하지 않는다

위해서다 — 느린 출혈형(닷컴), 시스템 위기형(금융위기), 외생 충격형(코로나).

| 국면 | 기간 | 성격 |
|---|---|---|
| 닷컴 붕괴 | 2000-01-01 ~ 2002-10-09 | 느린 출혈형 하락 |

국면 분류는 **사후적**이므로 매매 규칙에는 쓰지 않는다. 성과 분해에만 쓴다.

## §5. 알려진 한계

- 국면별 성과 비교는 충분표본을 충족한 셀이 9/30에 그쳤고 폭락 국면에서는 비교 가능한 셀이 없었다.
- D13의 변동성 결과에는 층 지배와 창 중첩이 남아 있으며, 대안 변동성 모형과 클러스터 축약 절차의 민감도는 검증하지 않았다.
- 파라미터 히트맵·워크포워드·개별 종목 분석 등은 1단계에서 실시하지 않았고 2단계로 이월한다.
- 따라서 현재 결과는 특정 신호의 실용적 전략성보다 검증된 범위와 남은 검증 과제를 제시하는 단계로 해석한다.
