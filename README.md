# S&P 500 기술적 지표 전략 분석 (2000–2026)

기술적 지표 기반 매매 신호가 **무작위 진입 대비 초과수익을 내는가**를
26년(2000–2026) S&P 500 데이터로 통계적으로 검증한 프로젝트.

세종대학교 소프트웨어학과 최준연 교수님 지도 과제 · 2026.08

---

## 핵심 질문

> RSI·볼린저밴드 신호는 아무 날이나 사는 것보다 나은가?
> 그리고 **아니라면, 왜 아닌가?**

S&P 500은 표본 기간 내내 우상향했다. 따라서 신호를 따라 매수해서 돈을 벌었다는 사실
자체는 아무것도 증명하지 않는다. 이 프로젝트는 절대 수익률이 아니라
**무작위 진입 대비 초과분**과 그 **p-value**로 신호를 평가한다.

## 데이터

| 항목 | 내용 |
|---|---|
| 신호 생성 | `^GSPC` (가격지수, OHLC 존재) |
| 벤치마크 | `^SP500TR` (총수익지수, 배당 재투자 반영) |
| 수집 구간 | 1990-01-01 ~ (지표 워밍업용) |
| 분석 구간 | 2000-01-01 ~ (닷컴·금융위기·코로나 3종 폭락 포함) |
| 출처 | yfinance, `auto_adjust=False`로 원본 보존 |

## 시장 국면

| 국면 | 기간 | 성격 |
|---|---|---|
| 닷컴 붕괴 | 2000-01 ~ 2002-10 | 느린 출혈형 하락 |
| 회복·확장 | 2002-10 ~ 2007-10 | 완만한 상승 |
| 금융위기 | 2007-10 ~ 2009-03 | 시스템 위기형 급락 |
| 장기 강세 | 2009-03 ~ 2020-02 | 저변동 상승 |
| 코로나 | 2020-02 ~ 2020-08 | 외생 충격 |
| 최근 국면 | 2020-08 ~ 현재 | 인플레·금리 사이클 |

## 방법론상의 원칙

- **미래 참조 차단**: 신호는 t일 종가로 확정, 진입은 t+1일
- **결측치 미보간**: 존재한 적 없는 가격을 만들지 않는다
- **벤치마크 정합성**: 배당(`^SP500TR`)과 현금 구간 무위험수익률을 모두 반영
- **다중검정 인식**: 파라미터 탐색 횟수를 명시하고 우연한 성능을 경계
