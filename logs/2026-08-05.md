### 자체 검증 6종 (외부 라이브러리 없이) — 전부 통과
- 갭 없음 → TR == 고가-저가 / 상방 갭 → `|H-C_prev|` 선택 (TR=22, 고가-저가는 2)
- 실데이터 18,422행에서 TR >= 0, TR >= 고가-저가 전부 성립
- 상수 시퀀스 → 상단==중심==하단, %B 규약 0.5, inf·NaN 없음
- %B 상단 1.0 / 하단 0.0 (오차 < 1e-12)
- 상수 시퀀스 → ATR == 0

### ta 대조
| 지표 | 결과 |
|---|---|
| 볼린저 5개 컬럼 (`ddof=0`) | **비트 단위 일치** (절대차 정확히 0) |
| 볼린저 (`ddof=1`) | 최대 절대차 **15.55** 지수 포인트 |
| ATR | 1995년 이전 최대 0.198 → 2000년 이후 평균 1.20e-14 (씨딩 차이) |

- **`pandas.std()` 기본값이 `ddof=1`이라, 명시하지 않으면 소리 없이 틀린 밴드가
  나온다.** ta는 `ddof=0`을 쓴다
- ATR은 D3의 RSI와 달리 **정확히 0에 도달하지 않는다.** RSI는 0~100 유계라
  흡수되면 영구 고정되지만, ATR은 값이 5→86으로 커져 1 ULP도 함께 커지기
  때문. 마지막 상대차 3.18e-16(머신 엡실론) → 상대차로 판정해야 갈린다
- **ta의 ATR 워밍업은 NaN이 아니라 0.0** (`np.zeros` 초기화, `fillna=False`에도
  해당). "계산 불가"가 "변동성 0"으로 바뀌는 것이라 신호 로직에 위험

## 방법론 기록

### (a)/(b)/(c) 분류 틀이 실제 판별력을 갖는다

| | D3 RSI 시드 차이 | D4 ATR 잔차 |
|---|---|---|
| 분류 | **(b) 가정 차이** | **(c) 반올림 오차** |
| 근거 | 씨딩 관례가 다름. 1992-03-27에 비트 단위 흡수 | 씨딩 차이 감쇠 후 남은 ULP 진동. 마지막 상대차 3.18e-16 |
| 결말이 갈린 이유 | RSI는 0~100 유계 → 흡수되면 영구 고정 | ATR은 값이 5→86으로 커져 1 ULP도 함께 커짐 |

**같은 라이브러리, 같은 평활 함수(`wilder_rma`)인데 분류가 갈렸다.** 틀이 모든
차이를 "구현 차이"로 뭉뚱그렸다면 이 구분이 나오지 않았을 것이다.
→ **2단계 프레임워크 대조 리포트 서두 재료.**

### 평활 압축 교정값

$$
\frac{\text{RSI (14일 Wilder 평활)}}{\text{\%B (평활 없음)}} = \frac{1.247}{1.697} = 0.735
$$

**평활이 유계 지표의 국면 간 배율을 약 26% 깎는다.** %B 예측에서 방향(RSI보다
위)은 맞혔으나 중심값 1.45가 실측 1.697보다 낮았는데, 평활의 압축 효과를
과소평가한 것이 원인이다. **유계 지표끼리 비교할 때 다음 예측에 반영한다.**

### 예측의 난이도 구분

전 항목 적중이지만 실질 난이도가 다르다. "전부 맞혔다"로 뭉뚱그리면 리포트에서
과장으로 읽힌다.

- **산술에 해당하는 것:** ATR 원값 6.049, 최대/최소 국면, 순서 예측.
  `ATR_raw = ATR% × C`는 항등식이라 두 요인을 알면 답이 나온다.
  "잘 맞혔다"가 아니라 **"계산이 맞았다"**.
- **실질적 예측은 %B 하나뿐이었고, 절반만 맞았다.** 방향은 논증했으나
  중심값 근거는 약했다.

### 반증선 판정의 정당성

ATR 원값 분해 상한이 예상 9.3 → 실측 10.23으로 움직였으나 판정은 유효하다.
상한은 원 데이터에서 **결정론적으로 계산되는 값**이고, 내가 입력 추정치(가격
배율 3.8)를 부정확하게 어림했을 뿐 **판정 기준의 정의는 사전에 고정**돼 있었다.

**8/6 순열검정에서 유의수준을 정할 때 같은 구분을 적용한다** — 데이터가 정하는
값을 정확히 계산해 넣는 것은 정당하지만, **결과를 본 뒤 임계를 옮기는 것은
정당화되지 않는다.**
