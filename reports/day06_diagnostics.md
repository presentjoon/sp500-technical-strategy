# D6 사후 진단 — S1 h=1 유의성의 대안 설명 검토

**작성일**: 2026-08-07 (D6 잔여 작업)
**대상**: `docs/signal_spec.md` §6.5 순열검정 결과 중 S1 h=1
**상태**: Phase 0 — 사전 약속 기록 완료, 진단 미실행

---

## 1. 문서의 지위

**이 문서는 사후 탐색적(post-hoc exploratory) 진단이다. 확증 검정이 아니다.**

| 항목 | 내용 |
|---|---|
| 확증 판정 | **원안 유지.** S1 h=1, $p = 0.0019$, Bonferroni 통과 |
| 검정 family | **불변.** $m = 20$, $\alpha_{adj} = 0.0025$ |
| 사전등록 항목 | 임계값·지평·신호 목록·시드·$B$ 일절 변경 없음 |
| 이 문서의 값이 쓰이는 곳 | "이 유의성을 어느 정도 신뢰할 것인가"의 근거. D12 국면별 매트릭스와 D14 `why_it_fails.md`의 재료 |

이 진단으로 얻은 어떤 수치도 `docs/signal_spec.md`의 §4~§7(사전등록 본문)에
반영하지 않는다. §8 한계 항목에 **이 문서를 가리키는 포인터 한 줄**만 추가한다.

---

## 2. 사전 약속문

> **본 진단은 결과와 무관하게 전량 기록한다. S1 h=1의 확증 판정은
> 원안(p=0.0019, Bonferroni 통과)을 유지하며, 진단 결과에 따라 판정·임계값·검정
> family를 수정하지 않는다.**

이 문단은 진단 실행 **전에** 작성해 커밋했다. 결과를 본 뒤 판독 기준을 옮기는
것을 막기 위한 장치이며, 커밋 시각이 그 증거다.

---

## 3. 진단 동기

D6 순열검정 20건 중 Bonferroni($\alpha_{adj} = 0.0025$) 통과는 **S1 h=1 단 1건**
이다. $p = 0.0019$, 몬테카를로 표준오차 0.00044, 임계값까지 **1.38 SE**인
경계 사례다.

이 유의성에 대해 **두 개의 대안 설명이 검토되지 않았다.** 둘 다 순열검정의
**교환가능성(exchangeability)** 가정이 깨지는 경우이며, 중요한 것은
**둘 다 p-value를 과소 추정하는(= 가짜 유의성을 만드는) 방향으로만 작동한다**는
점이다. 즉 어느 쪽이 참이든 실제 유의성은 보고된 것보다 약하다.

### 대안 1 — 분산 불일치

순열검정은 전체 거래일에서 **균등하게** 재표집한다. 그런데 S1 신호일은
급락 직후이고, D2에서 확인한 변동성 군집(volatility clustering) 때문에
**사후 변동성이 무조건부보다 높을 가능성**이 있다.

그렇다면 균등 재표집으로 만든 귀무분포는 실제보다 **좁아진다.** 관측값이 그
좁은 분포에 놓이므로 실제보다 극단적인 백분위를 받고, p-value가 과소 추정된다.

### 대안 2 — 국면 구성

RSI < 30이 하락 국면에 편중되어 발동한다면, 검정이 탐지한 것은 **"사건의
특이성"이 아니라 "하락 국면 탐지기"** 일 수 있다. 신호일과 무작위일의 차이가
신호 자체 때문이 아니라 두 집합이 서로 다른 시기에서 뽑혔기 때문일 수 있다.

D6에서 본 중첩 진단(간격 중앙값)은 **국지적 뭉침만** 보므로 시대적 편중을 잡지
못한다. S1의 간격 중앙값이 32거래일로 "양호"였다고 해서 사건이 시기적으로 고르게
분포한다는 뜻은 아니다.

## 4. 진단 A — 분산비 (계획)

D6에서 만든 사후 수익률과 신호 마스크를 **재사용**한다. 재계산하지 않는다.

5개 신호 × 4지평 = 20조합 각각에 대해 산출한다.

| 컬럼 | 정의 |
|---|---|
| `signal_id`, `h` | 조합 식별자 |
| `n` | 신호 표본 수 (창 잘림 제거 후) |
| `mean_sig`, `mean_all` | 신호일 / 전체일 사후 수익률 평균 |
| `sd_sig`, `sd_all` | 각 표준편차 (`ddof=1` 명시) |
| `sd_ratio` | `sd_sig / sd_all` |
| `t_naive` | `(mean_sig - mean_all) / (sd_all / sqrt(n))` |
| `t_adj` | `(mean_sig - mean_all) / (sd_sig / sqrt(n))` |
| `p_perm` | D6 순열검정 p-value (기존 값 그대로 옮김) |

`t_naive`는 균등 재표집 귀무분포가 **암묵적으로 쓰는 척도**이고, `t_adj`는
**신호일 자체의 산포**로 정규화한 척도다. **둘의 괴리가 대안 1의 크기다.**

저장: `reports/day06_diag_variance.csv`

### 판독 기준 (실행 전 확정)

| `sd_ratio` | 판정 |
|---|---|
| > 1.5 | 해당 조합의 순열 p-value를 **액면대로 해석하지 않는다** |
| 1.2 ~ 1.5 | **주의 구간** |
| < 1.2 | 분산 불일치가 실질적 문제는 아니다 |

## 5. 진단 B — 국면별 발동 편중 (계획)

국면 정의는 `src/config.py`의 `MARKET_REGIMES`를 그대로 쓴다 (하드코딩하지
않는다). 6국면은 닷컴 붕괴 / 회복·확장 / 금융위기 / 장기 강세 / 코로나 / 최근이다.

5개 신호 × 6국면 각각에 대해 산출한다.

| 컬럼 | 정의 |
|---|---|
| `signal_id`, `regime` | 식별자 |
| `n_days` | 국면 내 거래일 수 |
| `n_sig` | 국면 내 신호 발동 수 |
| `rate` | `n_sig / n_days` |
| `rate_ratio` | `rate / (전체 기간 rate)` |
| `share_sig` | `n_sig / (해당 신호 전체 n)` |
| `share_days` | `n_days / 6684` |
| `mean_uncond_h1` | 국면 내 **전체일** h=1 사후 수익률 평균 |
| `mean_sig_h1` | 국면 내 **신호일** h=1 사후 수익률 평균 |

**`mean_uncond_h1`과 `mean_sig_h1`을 나란히 두는 것이 이 진단의 핵심이다.**
국면 내에서도 신호일이 전체일보다 나쁘면 **대안 2로 전부 설명되지 않는다.**

저장: `reports/day06_diag_regime.csv`

### 판독 기준 (실행 전 확정)

> S1의 `rate_ratio`가 특정 국면에서 **3배를 넘고** 그 국면의 `mean_uncond_h1`이
> 전체 평균보다 **낮으면**, 대안 2가 S1 h=1 결과에 **실질적으로 기여한다**고
> 판단한다.

**표본 규칙:** 국면별 `n_sig`가 한 자릿수인 칸이 많을 것이다.
**`n_sig < 10`인 칸은 표에 값을 적되 해석하지 않는다.**

## 7. $B = 100{,}000$ 재실행 (계획) — 실행하기로 결정

> $B$는 **추정 대상을 바꾸지 않는 순수 몬테카를로 계산 파라미터**이므로 증가는
> HARKing이 아니다. 단 경계 사례에서 원하는 답이 나올 때까지 올리는 조작이
> 가능하므로, **1회만 실행하고 결과와 무관하게 기록한다. 확증 판정은
> $B = 10{,}000$, 시드 42의 원안을 유지한다.**

- S1 h=1 **하나만** 재실행. 시드 42 유지.
- 기록: p-value, 몬테카를로 표준오차, 95% 구간, $\alpha_{adj} = 0.0025$ 대비 위치

## 8. 이월 항목 (오늘 하지 않는 것)

**층화 순열(stratified permutation)** — 국면 내에서 재표집하거나, 후행 20일 실현
변동성 10분위 내에서 재표집하는 방식이 대안 1·2에 대한 **정공법**이다.
교환가능성이 깨진 축을 층으로 묶어 그 안에서만 섞으면 두 대안이 동시에 통제된다.

**그러나 오늘은 하지 않는다.** 층화 순열은 새로운 검정이며, 확증 family에 넣으면
$m$이 늘고 넣지 않으면 해석이 애매해진다. **D12 범위로 이월하고 오늘은 진단과
기록만 한다.**
