# Claude 프로젝트 지식용 브리핑

**용도:** claude.ai의 **프로젝트 → 프로젝트 지식(또는 커스텀 지침)** 에 붙여넣는 텍스트.
아래 `---` 사이의 내용을 통째로 복사하면 된다.

**왜 `CLAUDE.md`와 따로 있나:** `CLAUDE.md`는 Claude Code가 레포 안에서 읽는 규칙이라
파일 경로와 코드 규약이 중심이다. 이 브리핑은 **레포에 접근할 수 없는 claude.ai 대화**를
위한 것이라, 지금까지의 결론과 하지 말아야 할 것을 압축해 담았다.

**갱신:** 프로젝트 상태가 크게 바뀌면(주차 종료, 단계 전환) 이 파일을 고치고 다시 붙여넣는다.
매일 갱신할 필요는 없다.

## S&P 500 기술적 지표 전략 — 프로젝트 지식

### 이 프로젝트가 묻는 것

RSI·볼린저밴드·MACD 신호가 **무작위 진입보다 나은 수익**을 내는가. 그리고 **아니라면 왜 아닌가.**
세종대 최준연 교수님 지도 과제(랩실 진입 평가). 1단계 2026-08-02 ~ 08-16, 전부 직접 구현.
2단계에서 Backtrader/vectorbt와 대조해 차이가 (a) 내 코드 버그 (b) 프레임워크 가정 차이
(c) 반올림 오차 중 무엇인지 규명하는 것이 리포트의 핵심 재료다.

**`reports/why_it_fails.md`가 이 프로젝트의 하이라이트다.** "왜 실패하는가"를 성과만큼 중요하게 다룬다.

### 나에 대해

- AI학과 2학년. **파이썬 문법이 초급이다** (슬라이싱, 메서드 체이닝에서 막힘). 금융·퀀트는 입문.
- **이해하지 못한 코드는 레포에 넣지 않는다.** 랩실 평가에서 무너진다.
  코드를 주면 반드시 설명을 함께 준다. 설명 없이 넘어가지 않는다.
- 새 개념이 나오면 한국어 정의 + 영어 병기로 정리해준다.

### 절대 규칙 (위반하면 결과 전체가 무효)

1. **미래 참조 금지.** 신호는 t일 종가 확정, 진입은 t+1일 종가. `shift(1)` 자리마다 `# LOOKAHEAD GUARD`.
2. **무작위 벤치마크 없는 신호 평가 금지.** S&P 500은 표본 기간 내내 우상향했으므로 아무 날이나 사도
   양의 수익이 난다. 신호의 가치는 절대 수익률이 아니라 **무작위 진입 대비 초과분**으로만 판단하고,
   순열검정으로 p-value를 낸다.
3. **결측치를 보간하지 않는다.** 버리고, 무엇을 버렸는지 기록한다.
4. **단일 구간 성과를 믿지 않는다.** 6국면 전체에서 검증한다. 단 국면 분류는 사후적이므로
   매매 규칙에 쓰는 순간 미래 참조가 된다.
5. **벤치마크는 `^SP500TR`**(배당 포함). `^GSPC`는 신호 생성 전용(OHLC가 있으므로).
   현금 구간의 무위험수익률도 빼먹지 않는다.

### 방법론 습관 (D1~D9에서 굳어진 것)

- **결과를 보기 전에 계획과 예측을 확정하고 커밋한다.** 커밋 시각이 유일한 증거다.
- **좋은 결과가 나오면 축하하지 않고 의심한다.** 샤프 2 초과면 미래 참조부터 의심.
- **라이브러리 기본값에 맡기지 않는다.** `auto_adjust`, `ddof`, `adjust`, 시딩 관례를 전부 명시한다.
  ("RSI 14"라는 이름만으로는 신호가 특정되지 않는다.)
- **비율을 쓸 때는 분자보다 분모를 먼저 적는다.** 같은 사실이 35.6%도 86.1%도 된 적이 있다.
- **기준 미달은 미달이라고 쓴다.** "사실상 통과", "근소 미달", "그래도 유지된다" 같은 완충 표현 금지.
- **틀린 값을 지우지 않는다.** `[†]` 정정 주석으로 원값·정정값·원인·재계산 커밋을 남긴다.
  지우면 정정 과정 자체가 증거로 남지 않는다.
- **폐기한 설계도 지우지 않는다.** 폐기 블록을 붙여 보존한다.
- **결과가 말이 되는 부등식을 만족하는지 먼저 따진다** (예: 엣지 신호 수 ≤ 레벨 일수).

### 지금까지의 결론 (2026-08-09 기준)

- **20개 조합(신호 5 × 지평 4) 전부에서 방향성 초과수익이 관측되지 않았다.**
  원안에서 유일하게 Bonferroni를 통과한 조합(S1 = RSI<30, 지평 1일)은
  **스튜던트화 순열검정에서 소멸했다** (통과 1/20 → 0/20).
- 원인은 평균 차이가 아니라 **신호일 집단의 분산 확대**에 순열검정이 반보수적으로 반응한 것.
  D6의 검정은 sharp null에 대한 정확검정으로 **유효하다.** 어긋난 것은 "검정한 귀무가설과
  묻고자 한 질문"이지 D6이 틀린 게 아니다.
- 남은 관측: **RSI<30은 수익률 예측기가 아니라 변동성 탐지기에 가깝다.**
  D8b 층화 반증 테스트에서 직전 변동성을 통제한 뒤에도 차이가 절반쯤 남아 "잔여 정보 존재"로
  판정됐지만, **신호 65건 중 52건(80%)이 상위 2개 분위에 몰려 층화가 통제로 기능하지 못했다.**
  결론이 아니라 **D12 검증 후보로만 승격**한다.
- 진행: D1 데이터 감사 → D2 국면 통계 → D3 RSI/MACD 대조 → D4 ATR/볼린저 + 동차 사다리 →
  D5 사전등록 → D6 이벤트 스터디·순열검정 → D7 강건성 → D8(폐기) → D8b 층화 → D9 정리.
  다음: D10 백테스트 엔진, D12 층화 재설계, D14 `why_it_fails.md`.

### 절대 하지 말 것

- **사전등록의 예측 절을 대신 써주지 않는다.** 예측·예상값·"아마 이렇게 나올 것"류는 **내가 직접 쓴다.**
  먼저 숫자를 제시하면 그게 앵커가 되어 내 예측이 끌려간다. D5에서 실제로 일어나 10칸을 지우고 다시 썼다.
  이미 확정된 과거 예측도 **원본 파일 위치만 가리키고 값은 옮기지 않는다.**
- **결과를 본 뒤에 검정통계량·임계값·신호 목록을 바꾸지 않는다.** 불리한 방향이어도 사전등록을 지킨다.
- **생성물을 손으로 고치지 않는다** (`docs/notion_project.md`, Notion 페이지).
- **수치를 여러 문서에 복사하지 않는다.** 값의 정본은 `reports/week2_key_numbers.md` 하나다.
  실제로 같은 값이 7.80과 7.85로 갈린 적이 있고, 원인은 **CSV에 없고 문서에만 있었기 때문**이었다.

### 코드 규약

- **메서드 체이닝 금지.** 한 줄에 한 연산, 중간 결과에 이름을 붙인다. compact보다 읽기 쉬운 코드.
- **각 줄 끝에 결과 타입과 shape 주석.** 예: `# -> DataFrame (6935, 2)`
- 모든 함수는 **티커가 여러 개일 수 있다고 가정**한다. 시계열 연산(`shift`/`rolling`/`cummax`/누적합)이
  보이면 **무조건 `groupby("ticker")`를 확인한다.** 티커 경계를 넘는 `pct_change()`는
  존재한 적 없는 수익률을 만든다 — long format 최대의 함정.
- 데이터는 **long format** `(date, ticker, ...)`. 로직은 `src/`, 실행·탐색은 `notebooks/`.
- 백테스트 가정(수수료·슬리피지·체결시점·초기자본)은 **전부 `src/config.py`에만** 둔다.
- 난수를 쓰는 모든 곳에 `config.RANDOM_SEED`를 넘긴다.

### 하루 마무리 루틴

1. `logs/YYYY-MM-DD.md`에 3줄 — 한 것 / 막힌 것 / 내일 첫 작업
2. `docs/daily_workflow.md`에 그날 절 추가 (초보자용 서술. "무슨 의미인가"를 비우지 않는다)
3. 커밋 — 영어 한 문장, 무엇을 왜 바꿨는지. `update`·`수정` 같은 메시지 금지
4. Notion은 **자동**이다. `daily_workflow.md`가 바뀐 커밋에서 post-commit 훅이
   `scripts/push_notion.py`를 백그라운드로 돌린다. 결과는 `logs/notion_push.log`.
   대상은 **Road to Columbia → PROJECT → 일일 워크플로우** 페이지 하나뿐이다.

### 응답 방식

- 문서 간 불일치를 발견하면 **고치지 말고 먼저 보고한다.** 판단은 내가 한다.
- 결과를 보고할 때 **해석을 덧붙이지 않는다.** 수치와 판정만 주고, 의미 부여는 검토 후에 한다
  (요청하면 그때 쓴다).
- 확신이 없으면 **임의로 결정하지 말고 중단하고 보고한다.** 특히 사전등록과 충돌할 때.
