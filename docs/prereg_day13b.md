# §0. 연구 성격 규정

### (a) 연구 성격

본 분석은 완전히 독립적인 확증적 검정이라기보다, D8b에서 이미 관측한 **S1 신호 후 경로변동성 배율 1.81배 및 층화 후 1.41배**를 명시적인 추정량, 대조군, 층화 및 순열검정 절차로 정식화하여 재검증하는 분석이다. 따라서 효과의 존재와 방향에 대해서는 사전 관측이 존재하며 독립적인 확증적 검정으로 간주하지 않는다. 대신 D8b에서 충분히 고정되지 않았던 종속변수 정의, 스튜던트화, 신호군 가중 ATT형 층화, 중첩 처리 및 민감도 분석을 실행 전에 명시하여 실행 후 분석 선택의 자유도를 제한한다.

### (b) D8b 열람 사실과 사전등록 이유

D8b의 1.81배 및 층화 후 1.41배를 이미 열람했으므로 해당 수치를 이용한 §3 예측은 완전히 독립적인 사전 예측이 아니다. 이 사실을 숨기지 않고 본 문서에 명시한다. 본 사전등록의 목적은 기존 관측을 새로운 발견으로 가장하는 것이 아니라, 실행 후 종속변수 정의, 검정통계량, 층화 가중, 유의수준, 중첩 처리 및 민감도 분석을 결과에 맞게 변경하는 것을 방지하는 것이다. 이는 D12에서 D6 효과 크기를 §3의 입력으로 사용한 것과 동일한 논리 구조다.

### (c) 재현 예측과 신규 예측

D8b가 직접 관측한 효과 또는 그 효과를 동일한 척도로 재확인하는 항목은 **재현 예측**으로 분류한다. D8b에서 직접 검증하지 않았거나 본 분석의 새로운 설계에서 처음 검증하는 항목은 **신규 예측**으로 분류한다.

따라서 §3.1의 부호와 §3.2의 배율 구간은 D8b의 층화 후 1.41배를 재확인하는 **재현 예측**이다. §3.3의 스튜던트화 유의성과 축약 민감도에서의 유지 여부는 D8b에서 동일한 방식으로 검정되지 않았으므로 **신규 예측**이다. §3.4는 D8b에서 관측된 높은 σ_pre 편중이 층 내부에서도 남는지를 확인하는 것으로 **재현 예측**이다.

# §1. 측정 대상 정의

D8 폐기의 원인은 "변동성"이라는 단어가 서로 다른 두 양을 지시한 것이었다. 본 절은 §2보다 우선하며 표기 규약을 먼저 확정한다.

## 1.1 표기 규약

| 양                         | 창           | 관측 단위   | 문서 표기  | 코드 컬럼         |
| ------------------------- | ----------- | ------- | ------ | ------------- |
| 사전 실현변동성 (층화 변수) | [t−13, t] | 이벤트당 1개 | σ_pre | `pre_vol_14` |
| 사후 경로변동성 (**본 분석의 종속변수**) | [t+1, t+W]  | 이벤트당 1개 | σ_post | `vol_post_20` |
| 종점 수익률 횡단면 분산             | —           | 집합당 1개  | D(h)   | `disp_h{h}`   |

σ_pre의 창은 신호일 t를 **포함**한다(`pathvol.PRE_VOL_WINDOW = 14`, 로그수익률
14개). σ_post가 t를 제외하는 것과 비대칭이며, 이는 의도된 것이다. σ_pre는 t 시점에
관측 가능한 정보로 층을 배정하는 변수이므로 t일 종가까지 사용하는 것이 층화의
목적에 맞고, 미래 참조가 아니다. D8b·D12와 동일한 정의를 승계한다.

**규칙: 본 문서 및 산출물에서 "변동성"이라는 단어를 수식어 없이 단독으로 사용하지 않는다.** 항상 σ_pre / σ_post / D(h) 중 하나로 지시한다.

D12의 종속변수는 종점 수익률(`reports/day12_results.csv`)이며 본 분석의 종속변수와 다른 양이다. 두 결과를 직접 비교하지 않는다.

## 1.2 이벤트 창

### 창 시작

* **t+1**에서 시작하며 신호일 t는 포함하지 않는다.
* S1은 정의상 직전 하락을 요구하므로 t일 수익률이 체계적으로 크고 음수다. t를 포함하면 신호 정의 자체가 σ_post를 기계적으로 팽창시키며 이 편향은 대조군에 존재하지 않는다.
* 프로젝트의 진입 규약인 신호 t일 종가 확정 및 t+1 진입과도 정합적이다.

### 창 길이

* **W = 20 거래일 고정**
* 주검정은 W=20 단일이다.
* W=1은 표준편차가 정의되지 않으며, 짧은 창에서는 개별 σ_post 추정량의 오차가 커지므로 W=20을 사용한다.
* D8b의 W=20 관측과 동일 척도를 유지한다.

### 보조 분석

* W ∈ {10, 20}
* W=10은 기술(descriptive) 전용이며 유의성 판정 대상이 아니다.
* W=10은 **창 절단 조건만 W=10으로 재적용**한다.
* W=10에는 클러스터 축약을 적용하지 않는다.

## 1.3 창 절단 처리

표본 말단에서 t+W가 분석구간을 초과하는 이벤트는 **제외**한다. 보간하지 않는다.

* 제외 대상 신호 수: **0건**
* 제외 후 유효 신호 수: **65건**

절단은 D8b의 `valid_mask` 단계(`src/pathvol.py` 300행)에서 `post_vol.notna()`로 이미 적용되어 있으며, 분석 프레임이 6,684행에서 6,663행으로 축소된 상태다. 따라서 본 분석에서 추가로 제외되는 신호는 없다.

위 수치는 종속변수 값을 열람하지 않고 신호 인덱스만으로 계산할 수 있으므로 실행 전에 확정한다.

## 1.4 추정량

이벤트 t의 사후 경로변동성은 다음과 같이 정의한다.

```text
σ_post(t) = sqrt( (1/(W−1)) · Σ_{j=t+1}^{t+W} (r_j − r̄_t)² )

r̄_t = (1/W) · Σ_{j=t+1}^{t+W} r_j
```

* r_j: j일의 **로그수익률**이며 D12와 동일한 정의를 사용한다.
* 창 내 평균을 제거한다. RMS는 사용하지 않는다.
* `ddof=1`을 명시한다.
* numpy 기본값 `ddof=0`은 사용하지 않는다.

D8b의 `post_vol`은 `r_{t+2} … r_{t+21}`(진입일 t+1 이후)을 사용한다. 본 분석은
`r_{t+1} … r_{t+20}`으로 하루 앞선다. `r_{t+1}`은 t일 종가에서 t+1일 종가로의
변화이므로 신호일 수익률 `r_t`를 포함하지 않으며, §1.2가 배제하려는 기계적
팽창은 발생하지 않는다. §3.2에서 D8b의 1.41배를 기준점으로 쓰되, 창이 하루
어긋난 상태의 재현임을 §5에 명시한다.

## 1.5 척도 변환

검정은 **log σ_post** 위에서 수행한다.

군간 로그 차이를 Δ라 하면:

```text
exp(Δ) = σ_post(신호) / σ_post(대조)
```

로 해석한다.

따라서 D8b의 "1.81배", "1.41배"와 본 분석의 결과를 동일한 배율 언어로 비교한다.

## 1.6 연율화

연율화(√252 곱)는 **보고 목적으로만** 사용한다.

로그 스케일에서 연율화는 군간 차이 Δ에서 소거되므로 검정통계량, 순열분포 및 p-value는 연율화 여부와 무관하다.

## 1.7 대조군 정의

대조군은 분석구간 내 S1 신호가 발생하지 않은 거래일 전체 중 §1.3의 창 절단 조건을 동일하게 만족하는 날로 정의한다.

* D8b의 대조군 정의와 동일한지 여부: **동일**

D8b 사전등록 §2(`docs/prereg_d08b_pathvol.md` 21–27행)는 대조군을 비신호일만으로 정의하고, 창 절단 조건을 신호일·비신호일에 동일하게 적용한다. 본 분석의 §1.7 정의와 일치한다. 따라서 §3.2에서 D8b의 1.41배를 예측 기준으로 사용한다.

# §2. 설계

## 2.1 층화 구조

* 층화 변수: **σ_pre (14일 사전 실현변동성, 창 [t−13, t])**
* D8b·D12에서 사용한 정의를 그대로 승계한다.
* 층 경계: **확장 창(expanding window) 기준 5분위**
* 각 t의 층 경계는 t 시점까지의 정보만 사용한다. 미래 정보는 사용하지 않는다.
* 최소표본 규칙은 D12를 승계한다.
* 최소표본 기준: **5** (`src/pathvol.py` 77행 `MIN_SIGNAL_PER_BIN`)
* D12에서 Q1·Q2가 제외되었다.
* D13의 제외 층: **Q1(신호 1건), Q2(신호 2건)**
* 제외 후 유효 층 수: **K = 3** (Q3, Q4, Q5)
* 제외 후 유효 신호 수: **62건**
* 층별 신호 수: Q3 10 / Q4 20 / Q5 32
* 층별 대조군 수: Q3 1,132 / Q4 1,288 / Q5 1,586

신호군과 대조군에 각각 최소표본 조건을 적용한다.

* 층 내 신호 수가 D12 최소표본 기준 미달이면 해당 층을 제외한다.
* 층 내 대조군 수가 **10건 미만이면 해당 층을 제외한다.**

대조군 최소표본 기준 `n_k,ctl ≥ 10`은 사전 확정한다. 동일한 층 제외 규칙을 주검정과 민감도 분석에 적용한다.

## 2.2 검정통계량과 가중치

층 k에 대한 군간 로그 차이를 신호군 분포로 가중하는 ATT형 통계량을 사용한다.

```text
Δ = Σ_k w_k ·
    (mean_k[log σ_post | 신호]
     − mean_k[log σ_post | 대조])

w_k = n_sig,k / n_sig
```

w_k는 신호군의 실제 층 분포이므로 신호군의 자연적인 가중 구조를 보존한다. 층화에 의해 재가중되는 것은 대조군이다.

D12에서 관측된 Q5 가중치 **0.516**은 본 설계에서도 동일한 방식으로 보존한다.

균등가중 `w_k = 1/K`은 사용하지 않는다.

보고 시:

```text
ratio = exp(Δ)
```

로 배율을 산출한다.

## 2.3 스튜던트화

층별 군간 분산을 별도로 추정하는 **Welch형 표준오차**를 사용한다. pooled variance는 사용하지 않는다.

층 k에서:

```text
SE_k² =
    s²_k,sig / n_k,sig
    +
    s²_k,ctl / n_k,ctl
```

여기서:

* `s²_k,sig`: 층 k 신호군 `log σ_post` 표본분산, `ddof=1`
* `s²_k,ctl`: 층 k 대조군 `log σ_post` 표본분산, `ddof=1`
* `n_k,sig`: 층 k 신호군 표본 수
* `n_k,ctl`: 층 k 대조군 표본 수

전체 표준오차는:

```text
SE(Δ)² = Σ_k w_k² · SE_k²
```

관측 스튜던트화 통계량은:

```text
Δ_obs,stud = Δ_obs / SE(Δ_obs)
```

이다.

비스튜던트화 Δ도 병기 보고하지만 유의성 판정에는 사용하지 않는다.

## 2.4 순열 절차

* 순열 단위: **층 내 라벨 순열(within-stratum label permutation)**
* 층 경계를 넘는 라벨 교환은 허용하지 않는다.
* 반복 수: **B = 10,000**
* 난수 시드: **42**
* 판정 통계량: **스튜던트화 통계량**
* 양측 검정

층 내 라벨 순열에서는 각 층의 신호 수와 대조군 수를 고정한 채 라벨만 교환한다. 따라서:

```text
n*_k,sig = n_k,sig
n*_k,ctl = n_k,ctl
w*_k = w_k
```

이며 **순열마다 w_k를 재계산하지 않는다.**

각 순열 b마다 해당 순열의 군별 분산을 사용하여 SE를 다시 계산한다. 관측 SE를 순열에 재사용하지 않는다.

```text
Δ*_b =
    Σ_k w_k ·
    (mean*_k,sig − mean*_k,ctl)

SE*_b² =
    Σ_k w_k² ·
    (
      s²*_k,sig / n_k,sig
      +
      s²*_k,ctl / n_k,ctl
    )

Δ*_stud,b = Δ*_b / SE*_b
```

관측 통계량:

```text
Δ_obs,stud = Δ_obs / SE_obs
```

스튜던트화 p-value:

```text
p_stud =
(1 + #{|Δ*_stud,b| ≥ |Δ_obs,stud|})
/ (B + 1)
```

동일한 순열 표본에서 비스튜던트화 p-value도 계산한다.

```text
p_raw =
(1 + #{|Δ*_b| ≥ |Δ_obs|})
/ (B + 1)
```

**p_raw와 p_stud는 동일한 순열 표본, 동일한 seed=42로 생성된 B개의 라벨 배치에서 계산한다. 두 검정을 별도로 실행하지 않는다.**

## 2.5 창 중첩 및 민감도 분석

경로변동성은 창 중첩에 민감하다. 신호군뿐 아니라 대조군에서도 사후 20거래일 창이 연속 관측 사이에서 최대 19일씩 중첩된다.

따라서 대조군의 명목 표본 수가 수천 건이더라도 독립적인 정보량은 그보다 훨씬 작다.

20일 블록이 독립이라는 단순 근사에서는:

```text
n_eff,ctl ≈ n_ctl / W
```

로 볼 수 있다.

명목 표본을 독립 표본으로 취급할 경우 SE가 과소추정되고 p-value가 과소추정되는 방향의 문제가 발생할 수 있다.

### 중첩 진단

신호군과 대조군 각각에 대해 연속 관측 간격 g를 계산하고:

```text
overlap_ratio = count(g < W) / n_gap
```

으로 중첩률을 정의한다.

신호군에서는:

```text
overlap_ratio_sig ≥ 0.20 → flag
```

로 진단한다.

대조군의 중첩률은 연속 거래일 구조 때문에 구조적으로 1에 가까우므로 **진단 임계값을 적용하지 않고 기술 항목으로만 보고한다.**

축약 전 신호군 중첩률은 다음과 같다. 세 유효 층 전부 τ=0.20을 초과하므로 §4-3은 실행 전에 flag가 확정되어 있다.

| 층 | n_gap | count(g<20) | 비율 |
|---|---:|---:|---:|
| Q3 | 9 | 2 | 0.222 |
| Q4 | 19 | 5 | 0.263 |
| Q5 | 31 | 16 | 0.516 |

축약 후 중첩률은 1단계가 g ≥ 20을 강제하므로 정의상 0이며, 알고리즘 검산으로만 §5에 기술한다.

### 클러스터 축약 민감도

중첩의 영향을 확인하기 위해 **신호군을 먼저 확정한 뒤 대조군을 배치하는 2단계 축약**을 사용한다. 대조군이 신호를 밀어내어 신호군을 과도하게 감소시키지 않도록 하기 위한 것이다.

#### 1단계 — 신호 앵커 확정

신호일만 시간순으로 정렬한다.

1. 가장 이른 신호일을 첫 앵커로 선택한다.
2. 현재 앵커와의 거래일 간격이 `g < W(=20)`인 후속 신호를 제거한다.
3. `g ≥ 20`인 첫 신호를 새로운 앵커로 선택한다.
4. 전체 신호가 처리될 때까지 반복한다.

그 결과를 `S*`라 한다.

따라서 `S*`의 임의의 두 신호는 서로 20거래일 이상 떨어져 있다.

#### 2단계 — 대조군 배치

1. 원래 대조군에서 `S*`의 어떤 앵커와도 거래일 간격이 `20 미만`인 대조일을 먼저 제거한다.
2. 남은 대조일을 시간순으로 정렬한다.
3. 가장 이른 남은 대조일을 첫 대조 앵커로 선택한다.
4. 현재 대조 앵커와의 간격이 `g < W(=20)`인 후속 대조일을 제거한다.
5. `g ≥ 20`인 첫 대조일을 새로운 대조 앵커로 선택한다.
6. 전체 대조군이 처리될 때까지 반복한다.

그 결과를 `C*`라 한다.

따라서 `S* ∪ C*`의 임의의 두 관측치는 서로 20거래일 이상 떨어져 있다.

* 축약 후 신호 수: **34건** (최소표본 적용 후 유효 31건: Q3 7 / Q4 12 / Q5 12)
* 축약 후 대조군 수: **281건** (Q3 49 / Q4 44 / Q5 71)

축약 후에도 §2.1의 최소표본 규칙을 통과하는 층은 Q3·Q4·Q5로 주검정과 동일하다. 따라서 주검정과 민감도 분석은 같은 층 집합을 대상으로 한다.

가중치는 축약에 따라 변한다.

| | 주검정 (n=62) | 민감도 (n=31) |
|---|---|---|
| w_Q3 | 0.161 | 0.226 |
| w_Q4 | 0.323 | 0.387 |
| w_Q5 | 0.516 | 0.387 |

민감도 분석에서도 Welch형 SE와 순열별 SE 재계산을 그대로 적용한다.

주검정과 민감도 결과가 갈릴 경우 갈렸다는 사실 자체를 결과로 보고하며 어느 쪽을 사후적으로 선택하지 않는다.

### 축약 위상

축약 시작점은 각 단계의 첫 관측치로 고정한다. 20거래일 간격 서브샘플링은 시작 위상에 따라 결과가 달라질 수 있으며, 본 분석은 단일 위상만 사용한다. 위상 민감도는 검증하지 않았으며 §5의 한계로 기록한다.

# §3. 예측

## 3.1 부호 — 재현 예측

D8b에서 층화 후 S1 신호군의 사후 경로변동성이 대조군보다 높았으므로, 동일한 σ_post 정의와 대조군 구조를 사용하는 본 분석에서도 군간 로그 차이의 방향은 **양(Δ > 0)** 으로 예측한다.

**판정:** `Δ > 0`이면 참, `Δ ≤ 0`이면 거짓.

## 3.2 구간 — 재현 예측

D8b에서 관측된 층화 후 배율 **1.41배**를 기준점으로 사용한다.

로그 스케일에서 1.41배를 중심으로 배율 1.20배만큼의 대칭 범위를 설정한다.

```text
exp(Δ) ∈ [1.41 / 1.20, 1.41 × 1.20]
```

따라서:

```text
1.175 ≤ exp(Δ) ≤ 1.692
```

이고 보고 시 반올림하여:

**1.18 ≤ exp(Δ) ≤ 1.69**

를 사용한다.

단, §1.4에 기술한 대로 σ_post 창이 D8b와 하루 어긋나 있으므로, 본 구간 예측은
동일 추정량의 재현이 아니라 인접 창에서의 재현이다.

**판정:** `exp(Δ)`가 [1.18, 1.69]에 포함되면 참, 그렇지 않으면 거짓.

## 3.3 유의성 — 신규 예측

주검정에서:

**p_stud < 0.05**

를 예측한다.

클러스터 축약 민감도 분석에서도:

**p_stud,declustered < 0.05**

가 유지될 것으로 예측한다.

각 조건을 독립적으로 판정한다.

D8b에서 동일한 스튜던트화 및 축약 절차로 검정하지 않았으므로 신규 예측이다.

축약 후 유효 신호는 31건(층당 7~12건)으로 주검정의 절반이다. 따라서 민감도 분석의 검정력은 주검정보다 낮으며, 민감도에서 비유의가 나오더라도 이를 효과의 부재로 해석하지 않는다. 이 해석 규칙은 실행 전에 확정한다.

## 3.4 메커니즘 — 재현 예측

본 분석의 메커니즘 예측은 **σ_pre 층화 이후에도 신호군이 층 내부에서 상대적으로 높은 σ_pre를 갖는 잔차 편중이 남을 것**이라는 것이다.

사전적으로 확인 가능한 근거는 다음과 같다.

1. Q5의 신호군 가중치가 **0.516**으로 결과의 절반 이상을 차지한다.
2. D8b에서 **52/65개 신호가 Q4·Q5에 위치**하여 높은 σ_pre 구간에 강하게 편중되어 있었다.
3. Q5는 상단이 열린 층이므로 층 내부 σ_pre 범위가 넓다.
4. σ_pre가 높은 상태에서는 변동성 지속성에 의해 이후 σ_post 역시 높은 경향을 가질 수 있다.

따라서 5분위 층화가 신호군의 높은 σ_pre를 완전히 제거하여 층 내부 군간 σ_pre 차이를 0에 가깝게 만들 것이라고 예측하지 않는다. 오히려 **층화 이후에도 잔차적 편중이 남을 것**을 예측한다.

다음의 층 내 잔차 차이를 정의한다.

```text
Δ_pre =
Σ_k w_k · [
    mean_k(log σ_pre | 신호)
    − mean_k(log σ_pre | 대조)
]
```

**예측: `Δ_pre ≥ 0.10`**

**판정:** `Δ_pre ≥ 0.10`이면 참, `Δ_pre < 0.10`이면 거짓.

# §4. 진단 기준

모든 진단 항목은 사전 확정된 수치 임계값을 가진다. 임계값이 없는 항목은 기술 전용으로 강등한다.

| #   | 진단 항목              | 임계값                                                          | 조치                            |
| --- | ------------------ | ------------------------------------------------------------ | ----------------------------- |
| 4-1 | 층 지배도: `max_k w_k` | ≥ 0.50 → flag                                                | 결과가 단일 층에 의존함을 §5에 명시         |
| 4-2 | 층별 부호 불일치 가중치      | `Σ_{k: sign(Δ_k) ≠ sign(Δ)} w_k ≥ 0.25` → flag               | 층간 이질성을 §5에 명시                |
| 4-3 | 신호군 창 중첩           | `count(g<20)/n_gap ≥ 0.20` → flag                            | 민감도 결과를 주결과와 병기               |
| 4-4 | 층 내 잔차 편중          | `abs(Δ_pre) ≥ 0.10` → flag                                   | 층화 통제 실패로 판정                  |
| 4-5 | 스튜던트화 전후 p 변화      | (i) α 기준 유의↔비유의 교차 또는 (ii) `abs(log(p_stud/p_raw)) ≥ log(3)` | 해당 조건을 각각 보고하고 하나라도 발생하면 flag |
| 4-6 | 유효 신호 수 (원자료)      | `< 40` → flag                                                | 검정력 한계를 §5에 명시                |

## 4.1 층 지배도

`max_k w_k ≥ 0.50`이면 flag한다.

하나의 층이 결과의 절반 이상을 차지하는 경우 결과가 특정 층의 특성에 크게 의존할 수 있음을 §5에서 명시한다.

## 4.2 층별 부호 이질성

층별 로그 차이를:

```text
Δ_k =
mean_k(log σ_post | 신호)
−
mean_k(log σ_post | 대조)
```

로 정의한다.

전체 Δ와 반대 부호를 갖는 층의 신호군 가중치 합:

```text
W_opposite =
Σ_{k : sign(Δ_k) ≠ sign(Δ)} w_k
```

이 `0.25` 이상이면 flag한다.

## 4.3 창 중첩

신호군에 대해:

```text
overlap_ratio_sig =
count(g < 20) / n_gap
```

을 계산한다.

`overlap_ratio_sig ≥ 0.20`이면 flag한다.

대조군의 중첩률은 구조적으로 1에 가까우므로 **진단 기준을 적용하지 않고 기술 항목으로 보고한다.**

## 4.4 층 내 잔차 편중

다음의 Δ_pre를 사용한다.

```text
Δ_pre =
Σ_k w_k · [
    mean_k(log σ_pre | 신호)
    − mean_k(log σ_pre | 대조)
]
```

`abs(Δ_pre) ≥ 0.10`이면 flag한다.

특히 Δ_pre가 양수인 경우 신호군이 동일 층 내부에서도 더 높은 σ_pre를 갖는 것으로 해석하며, 층화가 σ_pre를 충분히 통제하지 못했음을 명시한다.

## 4.5 스튜던트화 전후 p 변화

비스튜던트화 순열검정의 p-value `p_raw`와 스튜던트화 순열검정의 p-value `p_stud`를 모두 보고한다.

다음 두 조건을 **각각 별도로 보고**한다.

1. `p_raw`와 `p_stud`가 α=0.05를 기준으로 **유의 ↔ 비유의로 교차**
2. `abs(log(p_stud / p_raw)) ≥ log(3)`

둘 중 하나라도 발생하면 flag한다.

p-value는 순열 p-value 산식의 `(1 + count)/(B+1)`에 의해 0이 되지 않는다.

## 4.6 유효 신호 수

§1.3의 창 절단 후 원자료 유효 신호 수가 **40건 미만**이면 flag한다.

축약 후 신호 수는 축약 알고리즘의 정의된 결과이므로 본 진단의 대상이 아니며, §5에 기술 항목으로 보고한다.

## 판정 규칙

flag는 결과의 무효화를 의미하지 않는다. flag가 발생하면 해당 진단이 의미하는 문제를 §5에서 반드시 서술한다.

flag 개수에 따라 결론을 자동으로 변경하지 않는다.

## W=10 보조 분석

W=10과 W=20의 `exp(Δ)`를 병기한다.

W=10은 창 절단 조건만 W=10으로 재적용하며 클러스터 축약은 적용하지 않는다.

두 값의 방향이 동일한지 여부를 기술하되 이를 근거로 유의성 판정을 변경하지 않는다.

기술 항목은 대조군 중첩률과 축약 후 표본 수를 별도로 보고한다. 클러스터 축약 후 유효 표본은 **신호 34건 중 31건, 대조군 281건**이다.

## 5.4 해석 한계

첫째, 유의한 배율은 알파가 아니다. σ_post의 유의한 차이가 발견되더라도 방향성 초과수익을 의미하지 않는다. D12에서는 방향성 초과수익에 대한 20개 조합이 모두 부정되었으므로 σ_post가 높다는 사실을 진입 근거로 사용하지 않는다. σ_post가 높다는 것은 진입 근거가 아니라 포지션 크기를 줄일 근거로 해석한다.

둘째, σ_pre_14는 산포만 측정하며 가격 경로의 모양을 완전히 표현하지 못한다. 같은 σ_pre라도 연속 하락과 양방향 진동은 이후 σ_post가 다를 수 있고, RSI<30은 이러한 경로 차이에 반응할 수 있다. 따라서 관측된 1.43배의 효과가 RSI 고유 정보에서 비롯된 것인지, 아니면 σ_pre_14가 가격 경로의 구조를 충분히 통제하지 못한 데서 비롯된 것인지 구분되지 않는다. 이는 D8b 결론 제약 (c)와 같은 지점이다.

셋째, 주검정은 원자료의 창 중첩을 직접 보정하지 않는다. 특히 대조군은 거의 모든 거래일을 포함하므로 20거래일 사후 창이 구조적으로 강하게 중첩된다. 따라서 명목 대조군 표본 수를 독립 표본으로 간주하면 SE가 과소추정되고 p-value가 낙관적으로 추정될 가능성이 있다. 통합 타임라인 클러스터 축약 민감도 분석은 이 문제의 영향을 평가하기 위한 것이며, 주검정과 민감도 결과가 다르면 그 차이를 그대로 보고한다.

넷째, 클러스터 축약은 신호 앵커를 먼저 확정하고 대조군을 배치하는 단일 그리디 절차를 사용한다. 축약 시작점과 그리디 선택 순서에 따라 결과가 달라질 가능성이 있으며, 본 분석에서는 별도의 위상 민감도 검증을 하지 않는다.

다섯째, σ_post 창은 D8b와 하루 어긋난다. 이는 §1.4에서 사전등록상 확인해야 할 설계 의무에 해당하며, 본 결과의 해석에서 해당 창 정의의 차이를 명시적으로 고려해야 한다.
